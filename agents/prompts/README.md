# Agent Prompt Templates

Ready-to-use system prompts for the governance and platform agents. Each prompt
enforces the platform's claims discipline and decision-support-only contract.

| Template | Agent | Purpose |
|---|---|---|
| [orchestrator.md](orchestrator.md) | OrchestratorAgent | Task dispatch coordination |
| [gatekeeper.md](gatekeeper.md) | GatekeeperAgent | Claims + ACL policy enforcement |
| [watcher.md](watcher.md) | WatcherAgent | Health/spec/test monitoring |
| [tallyman.md](tallyman.md) | TallymanAgent | Accounting and metrics |
| [chat.md](chat.md) | ChatAgent | Operator dialogue routing |
| [repo-agent.md](repo-agent.md) | RepoAgent (repo-agent pkg) | Per-repository sandbox steward |
