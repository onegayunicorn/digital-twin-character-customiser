# Digital Twin Character Customiser

A digital twin character customiser monorepo.

## Project Structure
- `cores/`: Core logic and system protocols.
- `engines/`: 3D and AI processing engines.
- `matrix/`: Data structures and transformation matrices.
- `3d/`: 3D assets and model files.
- `transitions/`: Animation and state transition logic.
- `web-app/`: Web integration and application interface.
- `documentation/`: Project specifications and research.
- `assets/`: General project assets.
- `extracted/`: Temporary storage for raw zip content.

## Quick Start
1. Explore the `documentation/` for platform specifications.
2. Check `extracted/` for initial 3D model assets.
